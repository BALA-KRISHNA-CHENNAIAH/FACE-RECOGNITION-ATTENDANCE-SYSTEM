# FACE-RECOGNITION-ATTENDANCE-SYSTEM
The attendance system uses Python, OpenCV, and Tkinter to automate tracking. Users register by capturing their image, which is stored for recognition. To mark attendance, they stand before the camera, and the system identifies them and records attendance in a CSV file. It ensures accuracy, prevents proxies, and simplifies record-keeping.
